# OntoSPK v2.0.0 — ontology core

The first selected public core combines native conceptual model 0.41.0 with bounded logical profile 0.43.0. This release includes the conceptual catalogue and figures, OWL and SHACL sources, competency-question contracts, synthetic fixtures, finite validation evidence, reference documentation, and third-party notices. It preserves the original native identifiers and ontology IRIs.

## Evidence

- Native model: 101 local classes, 27 external boundary handles, 286 associations, 34 generalizations and 22 scoped commitments.
- Published finite baseline: 374 exact-answer comparisons across 56 competency-question contracts, 13 HermiT outcomes, four targeted SHACL contrasts and a ten-stage integration receipt. Five reasoner populations and four SHACL populations are intentionally invalid; their expected rejection is a passing result.
- Accepted public candidate `5dc0933c76f1047d9751bfc13ac4316daad82a24` passed the ontology and documentation workflows (runs `39735045170` and `39735045210`). The release tag must identify the final public commit after publication metadata is updated.

## Scope limits

The 27 external handles are boundary records, without verified equivalence to owner ontologies. The expanded finite coverage programme is scheduled for v2.0.2. Independent expert acceptance, full UFO modal/causal semantics and production suitability are not asserted. Physical databases, industrial examples, an Explorer application and manuscript binaries are outside this release. Live Wiki, versioned Pages routes and browser-verified WebVOWL are tracked for v2.0.1; static source files are present here.
