Evaluation and evidence

OntoSPK publishes finite test outcomes and their limitations. The ontology core remains v2.0.0. The expanded evaluation increment is v2.0.2; GitHub Releases records its publication state. These overlapping denominators are not a semantic-correctness percentage.

Read the accepted scope and full closeout. All 1,977 SHACL components are accounted for, including 113 complex components. The bounded OWL profile passes OWL 2 DL and consistency checks; all 121 named classes are satisfiable, and 71 expanded HermiT scenarios match their expected results. All 56 CQ contracts pass 374 exact-answer comparisons. The default ROBOT report retains 812 metadata findings (288 ERROR, 451 WARN, 73 INFO); these are adjudicated, not claimed repaired.

Limits

Independent domain review, external-owner equivalence, modal and causal adequacy, and production readiness are not established by these finite checks. Read the limitations before reuse.
