Conceptual model

This is the preserved core specification or guide baseline. Ontology core v2.0.0 is unchanged; the accepted bounded FOL evidence is v2.0.6. Historical preparation labels and earlier test counts below retain their original context. Read the current formal verification method and version explanation and the evaluation overview. Reviewed diagrams and domains · Citation and evidence handoff · Current capability profile decision.

The native model is the source of the declared conceptual classes, stereotypes, association endpoints, multiplicities, generalizations and modeling commitments. It contains 101 local classes, 27 external handles, 286 binary associations, 572 association ends, 34 generalizations and one generalization set.

Read a relation together with both endpoint types and multiplicities. An endpoint multiplicity constrains instances at that end for each opposite-end instance. Relation direction in a query or physical table must be checked against the explicit mapping.

The complete structural reference displays every class, association, generalization and registered structural expression. Projection coverage distinguishes native entities from their OWL representation.

The selected diagram supports overview reading. Its omissions, selection and relation details remain recorded in the view manifest.
