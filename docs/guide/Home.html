OntoSPK describes software product knowledge across intended specifications, actual realizations and the evidence used to interpret them. This guide explains the selected public ontology core; the model and its recorded evidence remain the sources for exact definitions and test outcomes.

Understand the model

Read the Overview, Domains and Conceptual Model. The External References page explains which boundary links remain unresolved. Formalization and Constraints distinguish conceptual commitments, OWL meaning and finite data validation.

Examine the evidence

Quality states what the finite checks establish. Competency Questions identifies the query contracts; Reproduce gives executable instructions. Read Limitations before interpreting results beyond their tested scope.

Explore and cite

Visualization explains the selected diagram and WebVOWL view. Versions, References and Citation identify the release and its supporting sources. For exhaustive lookup, use the generated native reference and OWL declaration reference from the released source. The references are also available through the published Pages portal; current and frozen documentation have separate source identities.

Current documentation and decisions

The consolidated documentation/evidence increment is v2.0.8 over unchanged ontology core v2.0.0. Read the current status, FOL verification method, reviewed diagrams and domains and publication handoff. GitHub Releases records actual release publication; source preparation does not assert a completed DOI deposit.

Concept explanations and sources

The source-backed concept reader provides a categorized index of all 128 native entries and six editorial pilot pages, with canonical definitions, original explanations, examples and claim-specific IEEE-style references. Five local concepts and one external boundary have manuscripts; 122 entries await editorial coverage. Read the sourcing and maintenance method. This is a staged documentation increment under #37, not complete scientific validation or a new ontology core.
