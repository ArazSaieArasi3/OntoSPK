# OntoSPK documentation

OntoSPK describes software product knowledge across intended specifications, actual realizations and the evidence used to interpret them. This guide explains the selected public ontology core; the model and its recorded evidence remain the sources for exact definitions and test outcomes.

## Understand the model

Read the [Overview](Overview.md), [Domains](Domains.md) and [Conceptual Model](Conceptual-Model.md). The [External References](External-References.md) page explains which boundary links remain unresolved. [Formalization](Formalization.md) and [Constraints](Constraints.md) distinguish conceptual commitments, OWL meaning and finite data validation.

## Examine the evidence

[Quality](Quality.md) states what the finite checks establish. [Competency Questions](Competency-Questions.md) identifies the query contracts; [Reproduce](Reproduce.md) gives executable instructions. Read [Limitations](Limitations.md) before interpreting results beyond their tested scope.

[Visualization](Visualization.md) explains the selected diagram and WebVOWL view.
