Overview

This is the preserved core specification or guide baseline. Ontology core v2.0.0 is unchanged; the accepted bounded FOL evidence is v2.0.6. Historical preparation labels and earlier test counts below retain their original context. Read the current formal verification method and version explanation and the evaluation overview. Reviewed diagrams and domains · Citation and evidence handoff · Current capability profile decision.

OntoSPK organizes knowledge about software products while preserving distinctions between an intended specification, an actual realization and evidence about what occurred. A product can continue through changes to its versions and delivery arrangements; an execution record refers to a particular realized context rather than to the product in the abstract.

The conceptual model contains twelve local domains. External handles identify boundaries to independently governed subjects; a handle does not establish imported-class equivalence or approval by the external ontology owner.

The distribution provides a native conceptual model, a bounded OWL theory and SHACL constraints for supplied RDF graphs. Each has a different interpretation; the correspondence is documented rather than assumed to be lossless. The separate relational implementation is not included in this core distribution.

Read Domains, Formalization and Quality, then use Reproduce for executable examples. Limitations records the scientific and implementation boundaries.
