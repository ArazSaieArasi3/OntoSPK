# Citation and reuse

Cite the exact OntoSPK version and public repository commit used. The private source has a stable `v2.0.0` ontology-core release; the public repository is preparing its corresponding release. Until the public release or DOI exists, do not invent its publication date, DOI or public-release status. Machine-readable citation metadata is in [CITATION.cff](../../CITATION.cff).

The scholarly manuscript is managed separately. This repository does not redistribute an unpublished manuscript or licensed full-text sources. Associated publication metadata can be added after the appropriate publication decision.

See [licensing and reuse](../../LICENSING.md) before reuse. Third-party tools retain their licences and attribution. Public availability and scientific citation do not by themselves settle all reuse permissions.
