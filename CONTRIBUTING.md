# Contributing

Describe the modeling or implementation problem and identify the affected version, concept, relation or constraint. Include a small example when possible.

Semantic changes belong in the governed model or explicit profile first. Regenerate references and rerun the controls affected by the change. Documentation-only corrections should preserve definitions, evidence scope, limitations and version bindings.

Report unsupported claims, contradictory constraints, failed fixtures and broken public links through repository issues. Do not include private datasets or credentials. A proposed change is not independent scientific acceptance merely because it passes automated checks.
