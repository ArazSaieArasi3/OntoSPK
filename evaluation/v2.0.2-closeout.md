# Evaluation release v2.0.2 — closeout

**The finite evaluation release gate passes.** The ontology core remains v2.0.0; native and logical semantic source hashes are unchanged. There are zero unexplained positive-baseline failures and zero unaccounted SHACL component occurrences. This is not universal semantic or independent domain acceptance.

## Finding decisions

- **fixture_configuration**: Complete reporting graph needs the same retained ont_graph used by the released runtime; raw fixtures without it lack subclass context. The source graph was not changed. Disposition: RESOLVED_IN_HARNESS.
- **logical_unreachability**: 110 simple adverse cases cannot exist in isolation; source targetObjectsOf can also make isolated inverse missing-edge cases unreachable. Disposition: CLASSIFIED_NOT_COUNTED_AS_NEGATIVE_PASS.
- **method_limit**: 7814 data mutations survive exact-answer querying. All per-triple observations remain available; all 56 CQs detect at least one data mutation. No inference is used. Disposition: RETAINED_OBSERVATIONS.
- **editorial_metadata**: Default ROBOT report has 812 raw findings, including 288 ERROR. Labels, definitions and header metadata require an explicitly versioned follow-up; the lack of a project licence is an already disclosed rights state. Disposition: DEFERRED_SOURCE_REVIEW_NO_SILENT_REPAIR.
- **scientific_followup**: External-owner contracts, modal/causal adequacy and independent domain acceptance remain separate work. No semantic source defect was found by these finite tests. Disposition: OUTSIDE_V2_0_2.

## Reproduce

Use the pinned Python requirements and the SHA-256-verified ROBOT 1.9.11 JAR. Java 17 must provide the jdk.compiler module. Run from the repository root:

```bash
python tools/publication/test_shacl_complex.py
python tools/publication/test_owl_reasoning.py --robot "$ROBOT_JAR"
python tools/publication/test_cq_regression.py
python tools/publication/test_core_regression.py --robot "$ROBOT_JAR"
python tools/publication/adjudicate_evaluation.py
```

The expanded-evaluation workflow also regenerates the simple-component receipt and verifies the publication package. Native upstream SDK/validator results remain historical and are not relabelled as fresh. No owner decision is required to publish this bounded evaluation increment. Metadata improvements, external contracts and independent scientific assessment remain separate follow-ups.
