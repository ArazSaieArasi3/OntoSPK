STRUCTURAL FORMALIZATION OF THE PINNED NATIVE MODEL

This supplement makes the declared static structure explicit. It does not add
modal UFO semantics, establish independent acceptance, or assert equivalence
with OWL, SHACL or SQL. C[id] is a unary predicate and R[id] a binary predicate.
The quantifier domain is objects in one interpretation. card{...} counts
distinct related objects. These counting expressions abbreviate the usual
first-order existence/distinctness constraints; an unbounded maximum adds no
upper constraint. A 0..* bound is deliberately recorded even though tautological.

R(x,y) preserves native property order. The right-end multiplicity limits y
values for each x; the left-end multiplicity limits x values for each y.
External predicates are opaque boundary symbols, without accepted UFO typing.
Subclass implications do not assert that every class is populated. The one
generalization set is neither disjoint nor complete; neither condition is added.
Identity across time, essential dependence, event participation, mereology,
evidence truth and transition-policy integration require separate commitments.
No semantic reasoner, benchmark, or independent reviewer was run in this step.
