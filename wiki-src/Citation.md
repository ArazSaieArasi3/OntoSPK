# Citation and reuse

Cite the exact OntoSPK version and public repository commit used. The public [v2.0.0 release](https://github.com/ArazSaieArasi3/OntoSPK/releases/tag/v2.0.0) identifies commit `ccea141bcc238a4aae47e631cadc1809b738bc73`. No DOI has been assigned. Machine-readable citation metadata is in [CITATION.cff](https://github.com/ArazSaieArasi3/OntoSPK/blob/v2.0.0/CITATION.cff).

The scholarly manuscript is managed separately. This repository does not redistribute an unpublished manuscript or licensed full-text sources. Associated publication metadata can be added after the appropriate publication decision.

See [licensing and reuse](https://github.com/ArazSaieArasi3/OntoSPK/blob/v2.0.0/LICENSING.md) before reuse. Third-party tools retain their licences and attribution. Public availability and scientific citation do not by themselves settle all reuse permissions.

For later evidence, cite the exact corresponding release independently of the core.
