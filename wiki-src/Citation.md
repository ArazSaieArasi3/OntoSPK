# Citation and reuse

Cite the exact OntoSPK version and public repository commit used. Until a release or DOI exists, do not invent a release date, DOI or stable-release status. Machine-readable citation metadata is in [CITATION.cff](https://github.com/ArazSaieArasi3/OntoSPK/blob/main/CITATION.cff).

The scholarly manuscript is managed separately. This repository does not redistribute an unpublished manuscript or licensed full-text sources. Associated publication metadata can be added after the appropriate publication decision.

See [licensing and reuse](https://github.com/ArazSaieArasi3/OntoSPK/blob/main/LICENSING.md) before reuse. Third-party tools retain their licences and attribution. Public availability and scientific citation do not by themselves settle all reuse permissions.
