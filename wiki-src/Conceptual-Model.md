# Conceptual model

The native model is the source of the declared conceptual classes, stereotypes, association endpoints, multiplicities, generalizations and modeling commitments. It contains 101 local classes, 27 external handles, 286 binary associations, 572 association ends, 34 generalizations and one generalization set.

Read a relation together with both endpoint types and multiplicities. An endpoint multiplicity constrains instances at that end for each opposite-end instance. Relation direction in a query or physical table must be checked against the explicit mapping.

The [complete structural reference](https://github.com/ArazSaieArasi3/OntoSPK/blob/v2.0.0/semantic/product/v2/reference/README.md) displays every class, association, generalization and registered structural expression. [Projection coverage](https://github.com/ArazSaieArasi3/OntoSPK/blob/v2.0.0/semantic/product/v2/reference/native-class-projection.csv) distinguishes native entities from their OWL representation.

The selected diagram supports overview reading. Its omissions, selection and relation details remain recorded in the [view manifest](https://github.com/ArazSaieArasi3/OntoSPK/blob/v2.0.0/semantic/product/v2/figures/Selected_View_Manifest_v0_45_0.json).
